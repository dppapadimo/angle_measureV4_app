# 📐 Angle Measure Pro v4

## Features
- Upload εικόνας
- Zoom + / -
- Pan
- Πολλαπλές γωνίες
- Labels A, B, C...
- Undo
- Grid overlay
- Snap (ευθυγράμμιση)
- Export εικόνας

## Χρήση
1. Upload εικόνα
2. Tap 3 σημεία
3. Σύρε για διόρθωση
4. Χρησιμοποίησε Snap/Grid για ακρίβεια

## Controls
+ / - → Zoom  
Undo → διαγραφή  
Grid → πλέγμα  
Snap → ευθυγράμμιση
